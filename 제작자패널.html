🛠 제작자 치트 패널

이 파일은 제작자만 가지고 있으세요. 플레이어에게는 게임 파일만 배포합니다.
① 연결 설정 (처음 한 번)
저장소 이름과 토큰은 이 폰/브라우저에만 저장돼요. 다른 사람에게 이 파일이나 토큰을 보여주지 마세요.
처음 설정 방법 (GitHub)
  1. 게임이 올라가 있는 GitHub 저장소 이름 확인.
    게임 주소가 https://AAA.github.io/BBB/ 이면 저장소는 AAA/BBB 예요.
    (저장소는 Public 이어야 해요. GitHub Pages 무료 사용 중이면 이미 Public)
  2. github.com 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. 이름은 아무거나, 기간(Expiration)은 원하는 만큼
  4. Repository access → Only select repositories → 위 저장소 하나만 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로 변경
  6. Generate token → 나온 github_pat_... 를 복사 (한 번만 보여줘요)
  7. 위 ① 에 저장소 이름과 토큰 입력 → 아래 ▶ 로 명령 실행
  8. 게임 파일의 CREATOR_GH_REPO 에도 같은 사용자/저장소 를 넣고, 수정한 게임 파일을 GitHub에 다시 올리기
명령은 저장소의 cheat.json 파일에 기록돼요 (처음 보낼 때 자동 생성). 게임은 이 파일을 20초마다 확인하므로 전달까지 최대 1분 정도 걸릴 수 있어요.
② 명령어를 직접 고치거나 추가하세요. ▶ 를 누르면 지금 접속 중인 모두에게 적용됩니다.
